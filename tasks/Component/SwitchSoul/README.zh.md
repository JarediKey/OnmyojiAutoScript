# 御魂预设切换

[English](README.md)

按名称切换时，通过 OCR 定位目标行，在名称框的垂直中心高度点击对应应用按钮，
避免点击可编辑的名称。

组件最多等待五秒定位目标，再观察界面最多五秒。确认弹窗可见时，以 0.8 秒
间隔重试确定按钮。只要观察到过弹窗，成功就必须满足：点击确定后，连续至少
0.8 秒、多帧确认弹窗消失且式神录标识可见。确认阶段不要求目标名称仍可见，
点击冷却也不等同于弹窗消失。

方案已经应用时，游戏可能不弹确认框。如果整个观察期都没有弹窗，组件在
以至少 1.5 秒间隔点击应用共三次后，要求目标名称和式神录标识仍可见，
且最后一次点击后稳定至少 0.8 秒，再接受此流程。这是一种有界的界面推断：
界面没有独立证据证明目标御魂已装备，无法完全区分连续漏点与方案已应用。

目标缺失、应用重试失败、未知页面和未完成的确认弹窗仍会抛出
`GameStuckError`，交由调度器恢复。按数字切换的行为不变。

在仓库根目录运行离线回归检查：

```sh
python -m unittest discover -s tests -p test_soul_confirmation.py -v
```

这些检查模拟界面帧和时间，不代表游戏实测通过。
