# 加成开关

[English](README.md)

1280×720 的加成面板中，圆形开关位于 x=844–904 栏。OCR 或加成图标只确定行，
不再通过文字宽度推算开关位置。完整圆形开关模板以 0.9 阈值区分运行／暂停状态，
点击已匹配开关的中心，不点倒计时或颜色条。

金币、经验、觉醒、御魂加成共用状态确认。已处于目标状态时不点击；否则最多
点击三次、间隔两秒，使用新截图确认，总等待上限十秒。不点击无法识别的状态。
失败返回 false，保留调用方已有的告警与退出行为。

检查：`python -m pytest tests/test_buff_switch_control.py`。真实故障截图仅保存在
Ebony，离线回放不操作游戏加成。
