# 式神委派

[English](README.md)

通过「完成」标签定位已完成的任务，再点击 OCR 标签底边下方 25 像素处的
式神头像，因为标签本身不可交互。多个任务完成时选择最上方的匹配项，
不会将多个标签的坐标合并。

领取奖励保留原有结算及对话处理。进入任务的点击间隔为三秒，最多尝试三次。
入口无响应，或连续 20 秒没有识别到奖励操作时，请求人工接管，不再重启游戏。
仅标签消失不视为领取成功。任务选择及调度不变。

离线检查命令：`python -m unittest discover -s tests -p test_delegation_rewards.py`。
故障截图用于验证点击位置；实际进入任务和领取奖励仍需部署后手动运行验证。
