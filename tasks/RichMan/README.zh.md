# 大富翁商城识别与分类导航

[English](README.md)

荣誉、魅力、契灵、友情、密卷屋、特殊、勋章和寄售屋的商品列表图标使用 0.7
匹配阈值，共 27 条规则。购买确认及滑动到底标志保持原有阈值。3号故障截图中
售罄蓝票的匹配分数约 0.72，现可识别；图标识别不代表购买成功。

## 按顺序切换分类

五个主栏目顺序为：特殊 → 斗技 → 友情 → 勋章 → 魅力。斗技展开的常驻／赛季
不计入主栏目。五个入口共用同一个方法，不再经“特殊”中转。

每张新截图都在整个右侧分类栏中识别可见标签，并将主栏目高亮与标签位置关联，
判断当前选中项，不再用顶部资源图标充当选中依据。高亮缺失或含糊时，选中项
记为未知。目标需在多张截图中保持选中至少 1 秒，才确认导航完成。

目标可见时直接点击，不滑动。目标顺序早于所有可见栏目时，**手指向下滑**，
露出上方栏目；晚于所有可见栏目时，**手指向上滑**，露出下方栏目。每次复用
已有 `RuleSwipe`／`swipe()`，等待 1 秒后重新截图。没有识别到任何标签，或目标
位于两个可见栏目之间却识别不到时，方向不明确，不盲目滑动。点击过目标后，
等待选中确认，不在切换过程中继续滑走。

最多滑动三次、点击目标三次，点击间隔至少 3 秒；进入杂货铺后的导航上限为
25 秒。失败抛出 `GameStuckError`，不会在未确认的分类中购买。商品列表滑动、
购买选项和商店返回行为不变。

离线检查：`python -m unittest discover -s tests -p test_shop_category_navigation.py -v`
（需要 OpenCV）。真实截图验证了斗技选中及可见标签；模拟状态覆盖双向滑动、
重试和选中确认。侧栏位移图片检查是合成测试，不是真实滑动录像。其他栏目选中
外观及实际侧栏手势仍需实机验证。

## 商城返回

`MallNavbar.back_mall()` 在等待商城标志时，将黄色返回按钮的点击间隔设为至少
3 秒。大富翁和神秘商店共用此方法，其他返回操作保留各自的间隔。

此间隔用于减少切换动画期间的快速连续返回，不改变结束条件：已返回庭院仍
不能满足商城标志，因此这种情况仍可能触发现有卡住超时。间隔修改已完成本地
检查，尚未验证实机效果。
