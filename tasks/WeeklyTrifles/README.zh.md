# 每周小杂事

[English](README.md)

地域鬼王分享最多尝试打开分享选择界面三次，点击间隔至少 3 秒。第三次点击后
再等待 3 秒，仍未出现就跳过。先检查目标界面、再判断次数，所以第三次成功仍
正常继续。一旦点击过分享，就不再穿插点击后方的挑战列表坐标。今日挑战入口
和挑战记录入口分别最多点击三次，整个进入阶段另有 30 秒上限。

进入失败时，记录“跳过分享、奖励未确认”，返回已识别的地鬼／探索／庭院页面，
然后继续其他已启用的每周项目，不会仅因分享选择界面打不开就重启游戏。
返回按钮各自间隔 3 秒。若 20 秒内仍无法确认安全的返回页面，则使用原有卡住
恢复机制，不会在未知页面上直接继续。

分享选择界面出现后的微信／二维码／奖励流程、其他分享项目及每周调度保持
原样。跳过的分享不会单独重试，需等下一次计划或手动运行每周小杂事。
回归测试不会实际执行对外分享。

离线检查：`python -m unittest discover -s tests -p test_weekly_area_share.py -v`。
尚未验证游戏实测效果。

## 摸鱼行动与执行顺序

启用的每周步骤按图鉴分享、地鬼分享、秘闻分享、惠比寿摸鱼存储、破碎咒符召唤
的顺序执行。`save_touch_fish` 默认关闭。启用后展开寮活动面板，进入摸鱼行动，
识别到持有福运御守足够支付费用时使用全部存储按钮，处理确认／奖励弹窗并返回
庭院。御守不足或存储超时会记录日志。本功能不会节省体力，页面导航与存储效果
仍需游戏实测。
