# 金币妖怪组队等待

[English](README.md)

每次创建公开房间后，等待四个队友位置全部有人，即含队长共五人。复用已有四个
空位模板：均不可见、房间及挑战按钮可见，且满员状态连续至少两秒、三张截图
确认后才提前开车。

等待达到 180 秒仍未满员，则以当前人数开车。游戏自带倒计时可能提前开始；
识别到准备或战斗界面时直接衔接战斗，不再额外点击。等待时使用已有的长等待
标记，避免普通的 60 秒无操作检测中断组队。

挑战点击间隔两秒，必须在十五秒内确认进入准备／战斗界面；不会仅因一帧房间
识别失败就当作已经开战。无法确认时沿用现有卡死恢复。此规则只适用于金币妖怪，
经验妖怪及其他邀请任务不变。

检查：`python -m pytest tests/test_gold_youkai_room_wait.py`。
