# 集体任务捐献奖励

[English](README.md)

材料捐献和喂 N 卡提交选中的物品后，按实际界面处理奖励弹窗，不再假设固定弹窗次数。
奖励可见性与点击冷却分开判断，并优先于任务列表检测。

结束需要满足：至少点击过一次奖励，提交按钮和奖励弹窗均不可见，
且任务记录标识连续三秒、多帧可见。出现下一层奖励或未知页面时重新计时。
首次点击奖励后不再重新提交。二十秒内无法确认完成则抛出 GameStuckError。

此流程支持观察期内的一次、两次或更多次奖励弹窗。
任务列表稳定三秒以后才出现的延迟奖励不在覆盖范围内。
捐献数量、任务选择及其他任务卡片的领奖处理均不变。

在仓库根目录运行离线检查：

```sh
python -m unittest discover -s tests -p test_collective_donation_rewards.py -v
```

这些确定性检查模拟界面帧和时间，不代表已实测游戏的奖励时序。
