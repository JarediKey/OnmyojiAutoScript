# 逢魔之时

[English](README.md)

在 **逢魔之时 → 逢魔任务选项** 中开启 **跳过所有战斗** 后，仍完成四次发现、
领取发现奖励，并处理密信答题和宝箱。小怪／小鬼王灯笼、结界战斗、灯笼中的
大型首领、每日逢魔首领及战前切换御魂均会跳过。宝箱仍按原有购买规则处理，
包括默认购买神秘的符咒；该开关不会关闭购买。神秘任务与完整流程一样不处理。

结束后返回庭院，沿用原有的下次运行调度。本模式不获取战斗奖励。各账号默认
**关闭**该选项，保留完整流程。增加选项本身不会启用逢魔任务，也不会改变账号
的任务时间。

OASX 在初始化导航控制器时获取附加翻译。后端更新后，如果新名称或说明未显示，
请重新启动 OASX，让它重新加载任务字段和翻译。
