# 对弈竞猜实现

[English](README.md)

本实现基于源头 dev `c1dc5059` 的 FrogBoss，包含 PR #1850（`670f194a`）。
自定义金额边框草稿和本地失败切换实现已废弃；生成资源保留源头规则值。

任务主循环只有在连续五秒、至少三张新截图均显示“休息中”时才结束；标记消失
会重新计时。可用下注按钮及胜负结算优先处理，短暂 loading 的休息画面不会直接
跳过该场。已经进入下注提交流程后的确认仍沿用源头行为。

下注先处理奖励说明弹窗，再处理背景控件；点击已匹配的 30 万袋身上部一次，
然后最多提交三次、间隔三秒，总等待上限 20 秒。已下注或休息状态可结束流程。
是否选择金额由成功执行选择方法记录，不使用独立选中边框图片。

可选的 Oas 策略会对当前可见游戏记录读取两次，不滚动。日期／场次、选择方和
胜负观察一致时，可补结算唯一的已有决策；含糊或冲突的记录不计为已验证。
有验证记录的来源权重为历史正确率减 0.5，新来源保持中立。尚无已验证赛果时，
博主多数意见和群体多数意见各计一票。

私有历史仍保存在 `data/frog_oas/<实例>.jsonl`，账号策略设置保留。离线测试
不会访问外部预测服务或进行游戏下注。检查命令：
`python -m pytest tasks/FrogBoss/test_frog_oas.py tasks/FrogBoss/test_betting_flow.py`。
实际识别和下注效果仍需游戏验证。
