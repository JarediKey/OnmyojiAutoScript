# 通用弹窗

[English](README.md)

任务预期出现普通“确定”或“确认”弹窗时，使用 `BaseTask.I_UI_CONFIRM_DIALOG`。
识别器复用 GlobalGame 的完整长按钮、小按钮、普通按钮、蓝色按钮和宽版“确认”图片，在
1280×720 画面的 `(350,300,600,400)` 内查找，并在实际匹配到的按钮内点击。
各样式共用一个点击冷却标识。任务内重复资源已删除；具体操作及完成判断仍由
调用任务负责。这个搜索范围更大的识别器没有加入未知页面的关闭列表。

宽版“确认”覆盖探索退出弹窗。裁剪后的弹窗回归图片验证实际确认位置，并检查
探索退出流程先处理该弹窗，再考虑继续点击返回。图片不包含账号或背景游戏信息。

“创建”“邀请”“开启”“确认重置”以及技能选择页面标记等不同含义或文字的按钮
保留独立识别。英杰试炼“确认重置”的图片和搜索区域已按当前弹窗更新，不能将
这些按钮直接等同于普通确认。

截图流程明确识别到游戏服务器断线提示后抛出 `GameStuckError`，由现有调度恢复
流程重启游戏，不点击内容未知的弹窗。战斗结算和商城收取过程中的御魂满仓提示
使用已有的通用“知道了”规则处理。

执行 `python -m pytest tests/test_shared_confirmations.py` 验证。图片检查及故障
截图回放均为离线验证，不能代替所有游戏模式的实机测试。
