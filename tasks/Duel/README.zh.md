# 斗技准备

[English](README.md)

源 PR #1971 处理名仕禁选和上阵确认。禁选页识别“已禁选”印章，出现后停止点击。
每场最多点击禁选五次；禁选页连续四十轮没有进展时，进入已有的退出战斗流程。
确认阵容有效且未被禁选后，点击确认区域 `(1120,560,120,85)`，再等待开战。

印章和确认区域保存在源 JSON 中，通过 `dev_tools/assets_extract.py` 重新生成。
离线检查位于 `tests/tasks/Duel/test_duel_ban_already.py`，覆盖模板区分和有次数限制
的点击，不代表所有当前斗技阶段均已实机验证。
