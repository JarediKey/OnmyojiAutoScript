# Android 用户选择

[English](README.md)

在 **脚本 → 设备 → Android 用户 ID**（`script.device.user_id`）中选择安装游戏的
Android 用户／分身。默认 `-1` 禁用用户选择，保留原有包名检测和应用控制行为。
`0` 选择主用户，正数选择已有的其他用户。通过
`adb -s <serial> shell pm list users` 查询实际 ID；桌面图标编号不一定等于
Android 用户 ID。命令说明见 Android 的
[多用户指南](https://source.android.com/docs/devices/admin/multi-user-testing)。

启用后，自动包名检测只搜索指定用户。首次任务操作设备前，以及每次 OAS 启动
游戏时，先验证用户、游戏安装状态及启动入口，然后启动目标用户环境，强制停止
该模拟器其他用户下的同包名游戏，再用明确的 `--user` 启动目标。不会停止其他
包名应用或其他模拟器中的游戏。前台验证同时检查活动所属用户 ID 和包名，最多
等待 30 秒。目标无效、命令失败或无法确认前台时请求人工接管，不会回退到其他
用户。需要启用现有的自动应用控制权限（`script.error.handle_error`）。

正常停止／重启游戏也只针对配置的用户。此设置不修改游戏账号数据，也不切换
桌面的系统用户。不提供分身并行控制、持续监控其他分身、或独立显示的截图／
触控。一个模拟器使用一个 OAS 控制实例，修改用户选择前先停止实例。

验证包括离线命令与状态测试，以及 MuMu 能力的只读检查。分身停止、启动和
游戏登录尚未实机测试。
